# Photos du site

## Photos à ajouter dans ce dossier :

### 1. chateau.jpg
Photo du château de Château-Renault (celle que vous m'avez envoyée)
- Format : JPG
- Dimensions recommandées : 1600px de largeur minimum
- Utilisée pour : la bannière de la ville et le fond de la section hero

### 2. brigitte.jpg (optionnel)
Photo de Brigitte Vengeon
- Format : JPG
- Dimensions recommandées : 300x400px
- Utilisée pour : la section "Notre Candidate"

## Comment uploader les photos :

1. Allez sur GitHub : https://github.com/votrevillevotrevoix/municipale-chateau-renault-2026/tree/main/images
2. Cliquez sur "Add file" > "Upload files"
3. Uploadez vos photos depuis `D:\Documents\Municipales 2026\`
4. Nommez-les exactement : `chateau.jpg` et `brigitte.jpg`
5. Commit les changements

Les photos apparaîtront automatiquement sur le site !

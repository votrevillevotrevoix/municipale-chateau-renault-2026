## 🛠️ **Comment utiliser le template**

### **1. Ouvrir le fichier**
- Téléchargez `Template-VVVV-Chateau-Renault-2026.pptx` depuis GitHub
- Ouvrez-le avec PowerPoint (Windows, Mac) ou LibreOffice Impress (gratuit)

### **2. Dupliquer les diapositives**
- **Clic droit** sur une diapositive dans le panneau de gauche
- Choisissez **"Dupliquer la diapositive"**
- Modifiez le texte selon vos besoins

### **3. Modifier le texte**
- **Cliquez** simplement sur le texte pour le modifier
- Le formatage (couleur, taille, police) est déjà appliqué
- Vous pouvez ajouter ou supprimer du texte

### **4. Ajouter des images**
- **Insertion** → **Image**
- Placez l'image dans une zone libre
- Ajustez la taille et la position

### **5. Réorganiser les diapositives**
- **Glissez-déposez** les diapositives dans le panneau de gauche
- Supprimez les diapositives dont vous n'avez pas besoin

## ✏️ **Personnalisation avancée**

### **Changer les couleurs (si nécessaire)**

Si vous devez ajuster une couleur :
1. Sélectionnez l'élément (texte, forme)
2. Allez dans **Format** → **Couleur de remplissage** ou **Couleur de police**
3. Choisissez **"Autres couleurs"** → **"Personnalisées"**
4. Entrez les codes RGB :
   - Vert foncé : R=44, G=95, B=93
   - Vert clair : R=127, G=209, B=174
   - Vert moyen : R=61, G=139, B=133

### **Ajouter des formes**

Pour ajouter des encadrés, flèches, etc. :
1. **Insertion** → **Formes**
2. Choisissez la forme voulue
3. Appliquez le vert foncé ou vert clair pour la cohérence

### **Ajouter des graphiques**

1. **Insertion** → **Graphique**
2. Choisissez le type de graphique
3. Modifiez les couleurs pour utiliser les verts de la charte

## 💡 **Conseils d'utilisation**

### **Pour une présentation efficace :**

✅ **Limitez le texte** : Maximum 5-6 points par diapositive
✅ **Utilisez des images** : Photos de Château-Renault, de votre équipe
✅ **Soyez cohérent** : Gardez la même structure pour les diapositives similaires
✅ **Pensez lisibilité** : Le texte doit être lisible même de loin
✅ **Numérotez si besoin** : Ajoutez des numéros de page en bas

### **Thèmes de présentation possibles :**

- 📋 Présentation du programme électoral
- 👥 Présentation de l'équipe et des candidats
- 🏛️ Projet pour la ville de Château-Renault
- 💬 Compte-rendu de réunion publique
- 📊 Bilan et propositions
- 🎯 Thématiques spécifiques (jeunesse, économie, environnement...)

---

## 🖨️ **Impression**

### **Pour imprimer vos diapositives :**

1. **Fichier** → **Imprimer**
2. **Choix du format** :
   - Diapositives pleine page (1 par page)
   - Documents (2, 3, 4 ou 6 diapositives par page)
   - Notes (avec espace pour écrire)

3. **Qualité** : Choisissez "Haute qualité" pour un bel rendu

---

## 📱 **Export en PDF**

Pour partager votre présentation sans PowerPoint :

1. **Fichier** → **Enregistrer sous**
2. **Type de fichier** : Choisissez **"PDF"**
3. Options :
   - Qualité : Optimisée pour l'impression
   - Inclure : Toutes les diapositives
